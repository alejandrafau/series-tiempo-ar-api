Cargar colecciones desde JSON

El archivo debe tener la estructura:

{
  "collections": [
    {
      "id": "ipc",
      "nombre": "Índice de Precios al Consumidor",
      "descripcion": "...",
      "concepts": [
        {
          "id": "indic:ipc-indice",
          "nombre": "IPC Índice",
          "descripcion": "...",
          "variables": [
            {
              "id": "region_estadistica",
              "nombre": "Región",
              "valores_posibles": ["NOA", "NEA", "Nacional"]
            }
          ],
          "variables_compatibles": [
            ["region_estadistica", "clasificacion_coicop"]
          ]
        }
      ]
    }
  ]
}

Si una colección o concepto ya existe, sus datos serán actualizados.
